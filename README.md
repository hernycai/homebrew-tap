# Homebrew Tap de hernycai

Repositorio oficial de Homebrew Tap para instalar aplicaciones de macOS desarrolladas por [hernycai](https://github.com/hernycai).

## Instalación de Aplicaciones

### 📝 Bloc de notas para macOS

Clon nativo del clásico Bloc de notas de Windows para macOS (Swift / AppKit), con soporte de texto sin formato, Markdown, modo oscuro, barra de herramientas y configuración personalizada.

#### 1. Instalar con Homebrew

```bash
brew install hernycai/tap/bloc-de-notas
```

O si prefieres agregar el tap primero:

```bash
brew tap hernycai/tap
brew install --cask bloc-de-notas
```

#### 2. Usar en CaskHub

En [CaskHub](https://caskhub.app/):
1. Ve a la sección **Manage ▸ Taps** (Administrar ▸ Taps).
2. Agrega el tap `hernycai/tap`.
3. ¡Verás **Bloc de notas** en la lista para instalarlo con un solo clic!

#### 3. Actualizar la aplicación

```bash
brew upgrade bloc-de-notas
```
